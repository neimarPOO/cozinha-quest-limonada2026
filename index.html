Configurações do evento

Esta versão usa localStorage. Faça backup JSON diariamente e use sempre o mesmo navegador/perfil. O painel administrativo não tem autenticação forte: mantenha-o sob supervisão do monitor. O jogo é um protótipo, não um mecanismo antifraude.

O Three.js é carregado de uma CDN na primeira abertura. Se estiver sem internet, o jogo permanece funcional no modo visual alternativo, mas sem cena 3D. Para funcionamento 3D totalmente offline em um único HTML, seria necessário incorporar o código completo da biblioteca ao arquivo.
