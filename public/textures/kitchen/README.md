# Mapas de madeira

Origem: exemplos do projeto Three.js, arquivos `examples/textures/hardwood2_*`:
https://github.com/mrdoob/three.js/tree/dev/examples/textures

Mapas diffuse, bump e roughness armazenados localmente. O projeto de origem é
publicado sob licença MIT; cópia em `public/vendor/THREE-LICENSE.txt`.
A implementação de luz de área é do Three.js r158, com adaptação do módulo para
namespace global; os créditos e a referência ao trabalho LTC foram preservados.
